# llm-chat 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 单机单用户的对话式助理：自然语言记账（二次确认+俏皮话）与新闻按需查询，回答以 json-render 富界面在单一聊天框内流式渲染。

**Architecture:** pnpm monorepo（`server/` Node+TS 单服务 = REST API + AGENT 运行时 + SQLite；`web/` Vue3+TS 聊天界面）。AGENT 用 glm-5.3-flash 工具调用循环 + json-render inline 模式（服务端持 catalog 出提示词并做文字/JSONL 分离，Web 端 registry 渲染）。所有写操作经 `op_proposals` 提议-确认生命周期，服务端强制幂等与失效。

**Tech Stack:** Vue ≥3.5、@json-render/core + @json-render/vue、zod ^4、Node 20+、TypeScript、better-sqlite3（FTS5）、OpenAI SDK（指向智谱兼容端点）、ECharts、rss-parser、@mozilla/readability、vitest + supertest（server）、vitest + @vue/test-utils（web）。

**Spec:** `docs/superpowers/specs/2026-10-27-llm-chat-design.md`（需求唯一来源，执行者必读；本计划的 Global Constraints 均摘自该文档）

## Global Constraints

- 仅监听 `127.0.0.1`，无鉴权；服务端口 `8787`，web dev `5173`（vite proxy `/api`→`8787`）
- 模型 `glm-5.3-flash`；OpenAI SDK baseURL `https://open.bigmodel.cn/api/paas/v4`；env：`ZHIPU_API_KEY`（必需）、`GUARDIAN_API_KEY`（可选）、`DB_PATH`（默认 `<server>/data/llm-chat.db`）、`PORT`（默认 8787）
- 金额统一人民币，库内 `amount_cents` 整数；日期时区 `Asia/Shanghai`（用 `Intl.DateTimeFormat` 带 timeZone 解析，禁止依赖系统本地时区）
- 提议生命周期：全局同时最多 1 个 pending；失效仅三条件（10 分钟 TTL / 明确取消 / 新提议取代）；重复执行返回首次 result_json
- 俏皮话 ≤30 字、基于真实统计、LLM 超时 5s 静默省略；新闻摘要 ≤100 字
- 新闻：按需抓取（无任何定时任务）；来源级 TTL 30min；单来源抓取超时 8s；仅 HN/Guardian 支持历史区间
- 上下文：最近 20 条消息 + token 超限截断 + pending 状态注入 + assistant spec 压缩为一行摘要
- 前端内存窗口 ≤100 条消息（滑动窗口，20 条/页）；DOM 虚拟滚动只挂载可见区
- 错误统一 `{code, message}`；工作目录非 git 仓库，Task 1 先 `git init`
- Windows 开发环境：脚本用 `cross-env`，路径用 `node:path`

## Review Focus

1. **SSE 跨包断行**：JSONL 行被拆在两个模型 chunk 之间（`{"op":"add",` + `"path":...}`）——分离器必须缓冲不完整行；且容错 ``` 代码围栏。测试钉在 Task 11。
2. **双通道幂等**：先点按钮确认、再用文字说"确认"（或双击按钮）——只产生一条账单，第二次返回首次结果。测试钉在 Task 7、Task 9。
3. **过期提议点击确认**：TTL 外/被取代后点「确认」→ 返回"提议已过期"错误，绝不写库。测试钉在 Task 7。
4. **父类目展开**：问"交通成本"必须= 加油+打车+停车+公交地铁+火车机票之和，且不与子类查询混淆。测试钉在 Task 6。
5. **FTS5 不可用降级**：环境无 FTS5 编译时，关键词检索自动降级 LIKE，不崩。测试钉在 Task 16（用环境变量模拟开关）。
